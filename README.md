# Landscape Remote for Spotify

A landscape-first remote control for Spotify that you add to your iPhone Home Screen from Safari.
No App Store, no signing, no build step: plain HTML/CSS/JS hosted on GitHub Pages.

It does **not** stream audio itself (Spotify doesn't allow that for third parties on iOS). It controls
whatever device is playing: the Spotify app on the same iPhone, a Mac, a speaker, a TV.

**Screens:** Now Playing (art, seek, play/pause, prev/next, shuffle, repeat, like, volume, device chip),
Playlists → tracks (tap to play, Play / Shuffle), Search (songs, albums, artists, playlists), Queue, Devices (tap to transfer).

## Requirements

- Spotify **Premium** (Spotify requires it for playback control, and since Feb 2026 for Development Mode apps in general).
- A Spotify developer app (free, 2 minutes). Development Mode allows up to 5 users per app.

## Setup

### 1. Host it on GitHub Pages

```sh
cd spotify-landscape
gh repo create spotify-landscape --public --source=. --push
gh api -X POST repos/<your-user>/spotify-landscape/pages -f 'source[branch]=main' -f 'source[path]=/'
```

After a minute the site is live at `https://<your-user>.github.io/spotify-landscape/` (note the trailing slash).

### 2. Create the Spotify app

1. Open <https://developer.spotify.com/dashboard> → **Create app**.
2. Redirect URI: `https://<your-user>.github.io/spotify-landscape/` — must match exactly, including the trailing slash.
   (The app shows the exact value on its first-run screen, with a Copy button.)
3. APIs used: tick **Web API**.
4. Copy the **Client ID**. There is no client secret involved (PKCE flow).

### 3. Install on iPhone

1. Open the GitHub Pages URL in **Safari**.
2. Share → **Add to Home Screen**.
3. Open it **from the Home Screen** (not Safari; the Home Screen app has its own storage, so a login done in Safari doesn't carry over).
4. Paste the Client ID → **Connect Spotify** → approve.
5. Start playing something in the Spotify app on any device, then control it from here.

The app remembers the login (tokens are refreshed automatically). Settings (gear icon) has Log out, Change Client ID, Reload app, and a Keep-screen-awake toggle.

## Notes and limits

- **Orientation:** iOS ignores the `orientation` manifest field and Safari has no orientation lock, so the app can't force landscape.
  The layout is landscape-first; in portrait it stacks and shows a small "rotate" hint.
- **Volume** can't be set on an iPhone that is itself the active device (Spotify API limitation); the slider is disabled then.
- **Search** is capped at 10 results per type for Development Mode apps.
- **Local files** in playlists can't be started via the API and are shown greyed out.
- Playback commands need an active device. If there is none, the app tries the first known device, otherwise it opens the Devices tab.
- Updates: after changing files, bump `CACHE` in `sw.js` so installed copies refresh. "Reload app" in Settings clears the cache too.

## Development

Everything is static. Serve the folder with any HTTP server (`python3 -m http.server`) and open it in a browser.
Spotify needs HTTPS for the redirect URI, so logging in only works from the deployed URL (or `http://127.0.0.1:PORT/`, which Spotify allows as a loopback exception if you register it).

Icons are generated by `icons/make_icons.py` (no dependencies).
